## The pitch

> For $4 a month, we rename your lazy AI agent's failed tasks 'strategic pivots' and email your boss the rebrand at 3 a.m., so it never has to explain itself again.

## How it works

`main.py` writes the one-sentence pitch to `/output/entry.txt`. The
program is fully deterministic: every run writes the exact same text.

```sh
python3 main.py
```
